> 分析对象：`AprilTag Offline Studio` → **全局平差(B)** 输出（16 帧 / 14 靶 / 182 观测 / RMSE **0.946 px**）
> 分析数据源：`data/calibration_scenes/20260916_145246_Home_real/`（`tags_map.yaml` + `raw_images/tag_observations.yaml`）
> 诊断报告：`data/tag_calibration_verification/ba_precision_diagnostic_report.md`（2026-09-18 21:26:43）

## 0. 结论速览

1. **当前 0.95 px 的瓶颈不是"角点检测不够准"，也不是内参/畸变。** 按实测数据做误差分解：**约 80% 的平方误差来自一个与标靶成像边长成正比的比例项（≈0.86%×边长）**，而纯像素噪声项只有 ≈0.15 px（已接近物理下限）。比例项只能来自**标靶物理几何一致性（法向/平面度/尺寸一致性）与观测几何（机位近共面导致法向弱约束）**，靠继续堆亚像素算法收效甚微。
2. **真正该先做的事只有三件**：① 补拍机位（打破近共面 → 强化标靶法向与深度可观测性）；② 标靶物理改版（硬基板 + 逐靶实测边长）；③ 修掉平差里 3 个"人为放大误差"的代码缺陷（阶段二鲁棒核、经验权重、逐靶尺寸自由度）。
3. **报告里的 `±5~37 mm` 三维不确定度是"虚高"的**：它是在世界锚定之前、以名义 50 mm 尺度算出来的，没有乘锚定尺度 0.6968（虚高 1.435×），且权重/病态方向未处理。实测跨次重建一致性 RMS 仅 **2.2 mm**（见 §2.5），说明该一阶估计器需要重新标定后才能作为验收依据。

## 2. 残差的定量归因（本次实测）

对 16 帧逐帧用地图做 PnP，统计 728 个角点残差：

```
全局一角点残差: RMSE=1.313px  mean|d|=1.075px  median=0.951px  p90=1.961px  max=7.971px
```

### 2.1 关键证据①：残差随"标靶成像尺寸"线性增长（反向证据）

| 标靶像面面积 | n | mean\|d\| | RMSE |
| :--- | :--- | :--- | :--- |
| <2000 px²（小/远） | 56 | 0.799 px | 0.939 px |
| 2000–4000 px² | 272 | 0.951 px | 1.114 px |
| 4000–7000 px² | 232 | 1.104 px | 1.313 px |
| 7000–12000 px² | 160 | **1.333 px** | 1.686 px |

线性拟合：`|d| ≈ 0.477 + 0.00862 × L_px`（L = 成像边长）

**物理解读**：如果误差来自"角点检测随机噪声"，标靶越大（每边像素越多、相对定位越准）残差应当越小或持平；实测却单调**变大**，且比例系数 0.86% 恰好与"角点位移正比于标靶自身尺度"的机制吻合。物理上只有三种机制能产生"∝L"的角点残差：

1. **标靶物理尺寸不一致**（每个 Tag 被 BA 强行约束为同一边长，实际打印/裁切有 0.5~2% 差异）；
2. **标靶非平面**（纸张翘曲/气泡，离面 δz 在斜视下产生 ∝(δz/s)·tanθ·L 的形状位移）；
3. **标靶法向（倾角）估计误差**（法向误差 δθ 使投影四边形透视形变，形状形变量 ∝L）。

三者都属于"标靶几何/观测几何"问题，**与角点检测算法、内参、畸变无关**。

### 2.2 关键证据②：残差与像面半径基本无关（排除畸变/内参主因）

| 归一化像面半径 r | n | mean\|d\| | 残差径向分量均值（正=向外） |
| :--- | :--- | :--- | :--- |
| 0.00–0.30 | 334 | 1.004 px | +0.245 px |
| 0.30–0.50 | 276 | 1.157 px | −0.052 px |
| 0.50–0.70 | 83 | 1.141 px | −0.402 px |
| 0.70–0.85 | 35 | 0.956 px | +0.329 px |

径向分量不随半径单调变化、边缘区残差反而不增 → **本数据集不存在显著的径向畸变残差签名**。这既是好消息（畸变小），也说明：靠"重新标定内参/加畸变模型"不会把 0.95 px 降下来。

> 注意：这不代表代码没问题。离线链路把畸变**硬编为 0**（见 §5.1），一旦换成畸变较大的镜头/分辨率，就会立刻变成主因。仍需实测内参并把畸变系数接进配置。

### 2.3 关键证据③：46% 的残差连"单靶 6-DoF + 相似变换"都吸收不了

对每个观测，用"尺度+旋转+平移"（4 自由度）去拟合"模型投影四边形 → 实测四边形"，剩余部分即**四边形形状失真**（任何位姿、尺寸、平移都无法补偿）：

| 成分 | 数值 |
| :--- | :--- |
| PnP 后总残差 | 1.075 px |
| 相似变换可吸收（位姿/尺寸） | 0.957 px |
| **形状残差（无法吸收）** | **0.490 px（占 46%）** |
| ├ 径向分量 | 0.889 px |
| └ 切向分量 | 0.466 px |

形状残差随边长同样线性增长：`shape ≈ 0.149 + 0.00492 × L_px`

即：**常数项 0.149 px 是"角点检测噪声下限"，剩余 0.34 px 全是随尺度增长的系统性形状失真。** 亚像素算法已经不再是瓶颈。

### 2.4 关键证据④：机位近共面 → 法向/深度弱可观测

对 16 个解算出的机位做 PCA：

```
相机位置包围盒: X 192~272 mm (仅 80mm)   Y 48~334 mm   Z 591~1120 mm
机位质心散布 RMS = 179.0 mm
机位主轴奇异值 = 642 / 303 / 95 mm   ← 第 3 维仅 95 mm（相对 500mm 工作距离）
平均入射角 cos = 0.897  →  平均斜视仅 26.3°，且绝大多数帧接近正视
```

平面标靶的**法向（倾角）本身就是弱可观测量**（经典平面 PnP 二义性），当机位集中在近似平面、且普遍接近正视时，BA 只能把每个靶的法向锁定在 ±1~2° 的不确定区间里 —— 这恰好会在重投影上留下"∝L"的形状残差（与证据③互相印证）。

同时，机位近共面会让整张地图的"全局深度/尺度"方向变得极平坦，直接导致 §2.5 的跨次尺度漂移。

### 2.5 关键证据⑤：实测跨次重建一致性 ≈ 2.2 mm

对比同场景两套产物（`config/tags_map.yaml` vs 场景 `tags_map.yaml`，同名 14 靶、同锚点）：

两次重建的 **BA 基线相差 2%**（788.8 mm vs 804.3 mm），而重投影 RMSE 几乎相同（0.9468 vs 0.9461）——
说明**重投影 RMSE 对"尺度/深度方向的系统偏差"完全钝感**：RMSE 好 ≠ 地图绝对精度好。这也是为什么必须引入"跨次一致性"作为 KPI。

另：单靶 PnP 反推世界坐标的跨帧散布为 **5.7~19.4 mm（中位 14 mm）**，即"单次观测"的 3D 噪声量级；融合 9~16 次后落到 mm 级，与上表 2~3 mm 自洽。

## 4. 行动清单

### P0（本周，改动小、收益大）

1. **补拍机位**（针对 R1）——建议 30~40 帧：
   - 机位在 `X / Y / Z` 三个方向都拉开 ≥300 mm（当前 X 只有 80 mm、Z 主成分外仅 95 mm）；
   - 入射角覆盖 **0°、±20°、±40°**，每靶至少 8 帧、关键靶 12 帧以上，尤其补 Tag26 / Tag21 / Tag0；
   - 采图期间 **Tag 0 必须静止**（它是 SCARA 轴心动态 yaw 靶，转动后会被 BA 当静止靶处理，直接污染残差）。
2. **阶段二鲁棒核改为线性**（针对 R3）：见 §5.2 的补丁。
3. **不确定度报告乘以锚定尺度**（针对 §5.3 的单位缺陷）：不改会让 3σ 虚高 1.435×。
4. **采集端加 blur 拦截**：对每帧用角点邻域梯度能量/边缘宽度算 blur score，超阈值提示重拍；同时锁定彩色流曝光与白平衡。

### P1（两周内，需硬件/数据配合）

5. **标靶物理改版**（针对 R2）：改用 1.5~2 mm 铝板或亚克力激光雕刻/UV 打印标靶；贴装前检查平整度（塞尺/直尺），避免纸张受潮与气泡。**Tag21 / Tag26 / Tag29 优先更换。**
6. **逐靶实测边长入库**：用游标卡尺或二次元测每枚标靶黑边边长（±0.02 mm），把 `marker_size_mm` 从全局常数升级为**每靶可选字段**，或在 BA 中为每靶增加一个"尺度自由度"（等价于把 R2 从"不可建模"变成"可吸收"）。
   同时复核打印比例：本次反算为 **34.84 mm**，而图纸设定 **40.0 mm**（差 13%）——请确认 PDF 打印是否被"缩放以适应页面"，或 `world_anchor` 坐标是否准确（见 §5.4）。
7. **权重模型升级**（针对 R4）：用本次已经测出的 σ(L) 直接构造权重。
8. **重建两次取一致性**：把"同场景独立重建两次、同名靶位置差 RMS"作为常态化 KPI（当前 2.2 mm）。

### P2（一个月内，体系化）

9. **内参复标**：charuco/棋盘格标定一次；把 `k1,k2,p1,p2,k3` 写入 `config.yaml` 并让离线链路真正读取（见 §5.1）。
10. **不确定度估计器标定**：用合成数据蒙特卡洛（已知 σ，重复 BA 数百次）标定 `compute_3d_uncertainties` 的尺度因子，使其 3σ 与实测分布吻合；同时输出每个靶的"尺度一致性指标 `sc_i`"（本次帧间 std 已达 2.0%，是发现 R2 的敏感探针）。
11. **多通道角点融合**：`tag_super_extractor` 目前在 5 路增强图里"挑一条最好的"，可改为按直线拟合残差加权融合多路角点，把常数项 0.149 px 再压约 30%（收益小但便宜、无风险）。

## 5. 现行实现中的代码级缺陷（建议一并修）

### 5.1 离线链路把"畸变"硬编为 0（无法建模畸变）

`src/utils/config_guard.py`：

```56:57:src/utils/config_guard.py
    dist = np.zeros((5, 1), dtype=np.float64)
    ref_w, ref_h = 1920, 1080
```

`config.yaml` 的 `camera.color` 只存了 `fx/fy/cx/cy`，没有畸变系数；离线链路 `tools/studio/app.py` 调用时**不传 `stream_profile`**：

```219:222:tools/studio/app.py
    def _load_camera_intrinsics(self) -> Tuple[np.ndarray, np.ndarray]:
        """加载相机内参和畸变参数"""
        if resolve_camera_intrinsics is not None:
            K, dist, _ = resolve_camera_intrinsics(CONFIG_PATH)
```

→ 结果：`dist = [0,0,0,0,0]` 被固化进 BA。本次数据表明畸变当前不显著，但这是"运气"而非"保证"。

**修法**：`config.yaml` 增加 `camera.color.dist_coeffs: [k1,k2,p1,p2,k3]`，`resolve_camera_intrinsics` 读取它；并用 charuco 复标一次填入实测值。

### 5.2 阶段二仍使用强鲁棒核，导致"最小化的目标 ≠ 报告的 RMSE"

```391:402:src/calibration/ba_optimizer.py
        res_stage2 = least_squares(
            monitor2.wrap_residuals(residuals_func, obs_weights, outliers_detected), res_stage1.x,
            method='trf',
            loss='cauchy',
            f_scale=1.0,
            x_scale='jac',
            ftol=_BA_CONVERGE_TOL,
            xtol=_BA_CONVERGE_TOL,
            gtol=_BA_CONVERGE_TOL,
            max_nfev=200,
            verbose=0
        )
```

当残差量级本身就在 ~1 px 时，`cauchy + f_scale=1.0` 相当于对**所有**观测都施加了非线性压制，解会偏离最小二乘最优（被拉向"中位数解"），而报告里的 `rmse_px` 却是按原始逐角点残差算的 —— 于是"报出来的数不是被最小化的数"。

**修法**：阶段一（MAD 清洗前）继续用 Cauchy 抓粗差；阶段二在 `outliers_detected` 已压制的前提下改用 `loss='linear'`（或 `'huber'` 且 `f_scale≈2σ`）。

### 5.3 3D 不确定度：单位错（少乘锚定尺度）

```444:447:src/calibration/ba_optimizer.py
        # 5. 计算 3D 标靶空间坐标一阶协方差置信区间 (Uncertainty Estimation)
        tag_uncertainties = self.compute_3d_uncertainties(
            res_stage2.jac, static_tags_to_opt, base_static_id, rmse_px
        )
```

该调用发生在世界锚定（第 467~475 行 `anchor_to_absolute_world`）**之前**，此时坐标单位是"名义 50 mm 标靶尺度"，而锚定会整体乘 `scale = 0.696781`。报告却直接标注为 mm：

```489:490:src/calibration/ba_optimizer.py

            final_tags_map["uncertainties_mm"] = tag_uncertainties
```

→ `±5~37 mm` 全部**虚高 1/0.6968 ≈ 1.435 倍**（正确值约 `±3.9~25 mm`）。
另外 `compute_3d_uncertainties`（`src/calibration/ba_report.py:26-60`）用加权后的雅可比配"未加权"的 `σ_res`，且未处理 `pinv` 病态方向的偏置——建议按 §4 第 10 条做蒙特卡洛标定。

（已实测排除一个疑点：`scipy.optimize.least_squares` 在 `x_scale='jac'` 下返回的 `jac` 仍是**原始坐标**下的雅可比，`JᵀJ` 的量纲没有问题。）

### 5.4 名义边长 50 mm vs 图纸 40 mm vs 反算 34.84 mm

`tools/calibration/generate_apriltags.py` 图纸设定 `tag_size_mm = 40.0`；BA 名义初值 50.0；锚定反算真实边长 **34.839 mm**。
BA 对尺度不变，所以这不影响相对几何，但会：
- 让初值 PnP 的深度偏大 43%（收敛更慢、更易落入错误分支）；
- 掩盖"打印被缩放/锚点坐标有误"的真实问题；
- 若不同页面/批次的打印比例不一致（≈1% 级），则直接变成 §2.1 的比例项误差。

**修法**：把名义边长改为实测值作为初值，并做同一批次打印 + 100% 实际大小（禁用"缩放以适应页面"）的工艺约束。

## 6. 验收 KPI 与验证方案

### 6.1 建议的 KPI 体系（不能只看 px RMSE）

| KPI | 定义 | 当前值 | 目标 |
| :--- | :--- | :--- | :--- |
| 重投影 RMSE | 有效观测角点 RMSE | 0.946 px | ≤0.50 px |
| **比例项** | `|d|` 对 `L_px` 线性拟合的斜率 | **0.86 %/边长** | ≤0.30 %/边长 |
| **形状残差** | 相似变换无法吸收的四边形失真 | 0.490 px | ≤0.20 px |
| **跨次一致性** | 同场景独立重建 2 次，同名靶位置差 RMS | 2.2 mm | ≤1.0 mm |
| 最大单靶残差 | 单观测最大角点残差 | 7.97 px | ≤2.5 px |
| 3σ 空间不确定度 | 报告中已修正尺度后的值 | 待修正（虚高 1.435×） | 与跨次一致性同量级 |

> 前 6 项 KPI 可以用一次诊断脚本自动产出（见 §7），建议直接并入 `ba_precision_diagnostic_report.md`。

### 6.2 合成数据蒙特卡洛（用于标定不确定度估计器）

1. 取本次真实地图 + 机位作为真值；
2. 按已知 `σ=0.3/0.5/1.0 px` 注入高斯角点噪声，重复 BA 300 次；
3. 统计每个靶 3D 位置的实测散布，与 `uncertainties_mm` 对比，求尺度校正因子；
4. 固化为回归测试，保证"报告的 3σ"永远可解释。

### 6.3 快速 A/B 验收流程

```
改前: 记录 RMSE / 比例项 / 形状残差 / 跨次一致性
只改 R3+R4 → 复算 (预期 0.95 → 0.85 px)
再加 R1 (补拍) → 复算 (预期 → 0.65 px)
再加 R2 (硬基板+逐靶边长) → 复算 (预期 → 0.55 px 以内)
每一步都用同一套 KPI 表格比对，避免"RMSE 变好但尺度漂移"的假改善
```
