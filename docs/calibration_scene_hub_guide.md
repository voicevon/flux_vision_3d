# AprilTag 标定场景管理驾驶舱 (Scene Hub) 技术与操作指南

> **文档版本**: v2.1 (2026-09)  
> **适用模块**: `tools/calibration/tag_scene_hub.py` & `src/calibration/scene_manager.py`  
> **系统环境**: Windows 10/11 x64, Python 3.11+, OpenCV 4.x

---

## 1. 系统概述与设计哲学

在工业 3D 视觉与多 AprilTag 空间标定任务中，工程现场面临多视角采样批次繁多、不同工况/光照条件数据混乱、平差前缺乏直观质量体检，以及**测试标定参数与生产系统运行地图界限不清**等痛点。

**标定场景管理驾驶舱 (Tag Scene Hub)** 提供了一站式 1280x720 高清图形化控制台，打通了“**现场抓拍采样 $\rightarrow$ 几何健康体检 $\rightarrow$ 离线平差求解 $\rightarrow$ 留一盲测验证 $\rightarrow$ 一键生效生产系统**”的完整工业闭环。

---

## 2. 核心架构与【活动场景 vs 生产基准】机制

系统严格遵循**“草稿沙盒隔离、活动场景验证、生产原子发布”**的工业安全原则：

```mermaid
flowchart LR
    A[工况草稿沙盒] -->|设为活动 ⏎| B[🟢 当前活动沙盒 (Active)]
    B -->|C 采图 / S 平差| B
    B -->|P 生效到生产| C[★ 生产运行地图 (config/tags_map.yaml)]
    C -->|在线主程序读取| D[3D 视觉测量与定位生产环境]
```

### 2.1 状态定义

1. **草稿场景 (Draft Scene)**:
   - 本地独立文件夹保存原始图像与体检报告；
   - 处于孤立沙盒环境，修改、采图、平差求解绝不影响生产环境；
   - 卡片右上角显示灰白色 `[设为活动 ⏎]` 胶囊按钮。
2. **活动场景 (Active Scene)**:
   - 全局当前正在编辑、测试、采图、优化的唯一场景；
   - **核心绑定规则**：**仅当场景处于【活动中】状态时，卡片上才会出现 `[P 生效生产]` 专属按钮**，防止误发布非活动草稿。
3. **生产运行基准 (Production Benchmark)**:
   - 真正被系统生产管道（`config/tags_map.yaml`）加载的现场唯一真值地图；
   - 顶部 Header 中间醒目展示：`生产运行地图: 【XXX】`；
   - 对应的场景卡片右下角将获得金色荣誉徽章 `★ 生产运行`。

## 3. 界面布局与三模态视图指引

驾驶舱采用 1280x720 工业控制台深色科技风布局，支持三种无缝切换的视图模式：

```
+---------------------------------------------------------------------------------------------------+
| flux_vision_3d | 标定驾驶舱   [⊞标准|⤢大图|▤看板]   生产运行: 【现场基准】  [M]工具箱 [H]说明 [X]退出 |
+-------------------+-----------------------------------+-------------------------------------------+
| 工况场景批次 (5)    | 场景综合体检与几何健康报告         | 采样相册缩略图与单帧大图视口                |
| 01. 现场实测 [活动] |  - 基础指标卡片 (图像/Tag/RMSE)    |  - 多视角缩略图网格                        |
|     [P 生效生产]   |  - 几何网络健康度 (环路/跨度)      |  - 快捷按键 [< / >] 滚轮翻页               |
| 02. 对照组A        |  - 工业质检放行仪表盘              |  - 单帧大图全宽自适应 [F]                  |
|     [设为活动 ⏎]   |                                   |  (纯净看板模式下相册关闭，右侧940全景舒展) |
| ----------------- |                                   |                                           |
| 场景快捷操作:     |                                   |                                           |
| [N]新建  [R]改名  |                                   |                                           |
| [K]克隆  [V]目录  |                                   |                                           |
| [C]相机连拍采图   |                                   |                                           |
+-------------------+-----------------------------------+-------------------------------------------+
| [↑/↓]选场景 [⏎]设为活动 [P]生效生产 [C]连拍 [S]平差 [F]切换视图              CAM: ONLINE (D435) 30 FPS  |
+---------------------------------------------------------------------------------------------------+
```

### 3.1 三模态视图切换机制
- **模式 1：标准三栏视图 (`[ ⊞ 标准 ]`)**：左 340 场景卡片 + 中 460 体检健康报告 + 右 480 采样相册与大图；
- **模式 2：全宽大图沉浸视图 (`[ ⤢ 大图 ]`)**：左 340 场景卡片 + 右 940 大图自适应铺满全屏，用于巡检角点定位精度与高光反光；
- **模式 3：纯净体检健康大屏 (`[ ▤ 看板 ]`)**：左 340 场景卡片**绝对固定不动** + 右 940 宽松舒展展示**场景核心体检、几何网络健康度与 0~29 号 Tag 拓扑覆盖矩阵**，采样相册完全关闭隐藏，杜绝多余图形干扰；
- **切换方式**：鼠标点击顶部三段式 Tab 胶囊，或按键盘 **`[F]`** 键单键顺次循环。

### 3.2 顶部标题栏 (Header, 0~50px)
- **三段式视图 Tab 胶囊**：直观高亮指示当前所处模式，点击一秒直达；
- **生产运行地图信息**：居中展示当前实际在线的地图名称与物理 ID，点击可秒级唤出业务机制解析看板；
- **[M] 工具箱按钮**：点击唤出 6 合 1 独立标定工具总菜单；
- **[H] 生产说明按钮**：点击唤出【活动 vs 生产】黄金闭环全景流程弹窗；
- **[X] 退出按钮**：深红科技警戒按钮，支持**鼠标直接点击**或按 **[ESC]** 安全退出。

### 3.2 左侧导航栏 (Left Panel, 0~340px)
- **场景批次卡片列表**：单屏可容纳 5 个工况卡片，支持鼠标滚轮与方向键自由翻页；
  - **活动卡片**：展示 `● 活动中` 绿色徽章，并拥有专属的高亮 `[P 生效生产]` 按钮；
  - **草稿卡片**：展示 `[设为活动 ⏎]` 胶囊按钮，**鼠标点击或按回车键立即将其切换为当前活动沙盒**；
- **鼠标右键快捷上下文菜单 (Context Menu)**：
  - 在任意场景卡片上**点击鼠标右键**，即在光标处唤起专属深色科技浮层菜单；
  - 针对该条目的操作全部收敛进右键菜单中：
    1. **重命名场景别名**（快捷键 `[R]`）
    2. **克隆当前场景副本**（快捷键 `[K]`）
    3. **设为全局活动沙盒**（快捷键 `[⏎ Enter]`）
    4. **生效到生产系统**（快捷键 `[P]`，仅已完成平差场景可用）
    5. **打开该场景物理目录**（快捷键 `[O]`）
    6. **安全删除场景**（快捷键 `[DEL]`，活动场景/生产中场景受保护禁止误删）
  - 支持鼠标 Hover 高亮，点击菜单外空白处或按 `[ESC]` 安全关闭。
- **左下方全局级操作按钮**：按用户工效规范精炼保留核心全局功能：
  - `[+] 新建工况 [N]`：轻量级弹窗输入中文工况别名；
  - `[V] 场景总目录`：在 Windows 资源管理器中打开所有场景存放的总物理文件夹；
  - `[C] 相机连拍向导`：全宽醒目按钮，一键切入相机取流与连续抓拍。

### 3.3 中间报告栏 (Center Panel, 340~800px)
- **核心元数据卡片**：显示中文友好别名、物理 ASCII 目录 ID、样本帧数、求解状态；
- **基础体检指标**：全量样本检测标签总数、覆盖唯一 Tag 数量、全局 RMSE 重投影误差；
- **空间几何网络健康度**：跨视角最大基线跨度 (mm)、平均单帧标签冗余度、闭环观察数；
- **质检放行建议**：智能评估当前场景是否满足工业高精生产要求（RMSE < 0.8px 且几何健康）。

### 3.4 右侧相册栏 (Right Panel, 800~1280px)
- **缩略图网格**：展示当前场景已采样的每张视角图纸及检测到的 AprilTag 数量角标；
- **大图全宽预览 [F]**：按 `F` 键瞬间将中间与右侧栏合体为全宽高分辨率视口，利用滚轮顺畅巡检单帧角点检测品质。

### 3.5 底部状态栏 (Footer, 670~720px)
- **左侧操作提示**：实时反馈当前系统状态与 Toast 提示；
- **右侧 Camera 硬件状态胶囊**：
  - **仿真模式 (`--mock`)**：浅青色呼吸灯，显示 `CAM: MOCK (仿真流) 30.0 FPS`；
  - **物理在线 (RealSense D435)**：亮绿色呼吸灯，显示 `CAM: ONLINE (D435) 30.0 FPS`；
  - **待机就绪**：沉稳灰青色呼吸灯，显示 `CAM: STANDBY (硬件待机就绪)`。

## 4. 黄金闭环 3 步走 SOP 操作规范

生产现场推荐标准操作流程：

1. **Step 1: 新建或选定草稿场景**
   - 按 `[N]` 新建场景（输入中文别名，如 `20260915_车间产线标定`）；
   - 或选中历史场景，点击卡片右上角 `[设为活动 ⏎]` 将其设为活动沙盒。
2. **Step 2: 原地连拍采样与深度平差**
   - 点击 `[C]` 连拍向导或按 `C` 键切入相机流；
   - 移动相机多角度变换姿态，按 `[Space]` 空格连续抓拍 10~20 帧高质样本；
   - 按 `[S]` 启动 Studio 平差工作站，剔除粗差样本，求解全局 Tag 3D 空间坐标；
   - 观察中间栏体检报告：确认 RMSE 重投影误差优于 0.8px。
3. **Step 3: 严格质检后一键生效到生产**
   - 点击当前活动卡片上的专属 `[P] 生效生产` 按钮（或直接按键盘 `[P]` 键）；
   - 系统原子更新生产配置文件 `config/tags_map.yaml`，并建立时间戳安全备份；
   - 场景状态立即升级为 `★ 生产运行`，完成现场标定闭环！

## 5. 性能设计与高频交互优化

针对高频鼠标 Hover 与高帧率渲染，Scene Hub 实现了针对性极致优化：
- **局部轻量 Patch 文本绘制**：
  - 传统方案在每次绘制非 ASCII 中文时拷贝整张 1280x720 图像导致巨幅卡顿；
  - Scene Hub 采用基于 Bounding Box 的微小切片 Patch 局部贴图，内存操作量从 2.7MB 降低至 10KB；
  - 单帧渲染耗时由 >45ms 骤降至 <1.2ms，消除一切鼠标 Hover 迟滞。
- **Unicode / 中文路径安全兼容**：
  - 底层基于 `cv2.imdecode` 与 `cv2.imencode` 封装 `imread_unicode` 与 `imwrite_unicode`，杜绝 Windows 平台中文路径黑屏与加载失败。
