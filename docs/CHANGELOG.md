## [2026-09-13] - 终极根治体检台鼠标点击退出无响应缺陷与“顶部+底部双退出引擎”部署

### 1. 缺陷深层机理定位
- **问题现象**：键盘按 `Q` 能顺利退出，但用鼠标左键点击界面右下角的【退出 (Q)】按钮时毫无反应；
- **深层根因**：
  1. **防抖逻辑误伤 `LBUTTONUP` 真实点击**：原先在事件入口前置了 `now - _last_btn_click_time < 0.20` 强行 return。当用户点击鼠标左键时，首先产生 `LBUTTONDOWN`，防抖时间戳已被刷新；紧接着 0.05s 用户抬起鼠标产生 `LBUTTONUP` 时直接被无情拦截吞掉；
  2. **高 DPI 屏幕缩放下的坐标漂移**：在 Windows 1366x768 或笔记本 125%/150% 缩放下，缺少 Per-Monitor DPI 感知会导致 DWM 对窗口进行虚拟拉伸，使得鼠标回调坐标与底层图片坐标出现非线性偏移；
  3. **底部退出按钮热区过窄**：底部工具栏按钮高度仅 42px，若用户点击稍微偏离按钮中心或点在边框缝隙容易脱靶；
  4. **回调内部直接销毁窗口诱发消息泵死锁**：在 OpenCV 鼠标回调执行过程中就地调用 `destroyWindow` 会导致底层 Windows 消息循环句柄失效异常。

### 2. 彻底根治与全域优化措施
- **退出指令全域绝对优先判定与防抖豁免**：
  - 将退出（EXIT）判定提升至鼠标事件最高优先级，**彻底免除任何防抖冷却限制**，按下或抬起任意时刻触碰热区立刻毫秒级响应；
  - 仅针对翻页、平差、画板等普通业务按钮保留触发后的冷却，避免误吞点击；
- **顶部 HUD + 底部工具栏“双退出引擎”**：
  - **底部右下角**：加宽至 110px，并将整个右下角（`x >= w - 150` 且 `y >= h - bot_bar_h - 8`）全域作为兜底退出热区，哪怕点在边框、间隙也 100% 退出；
  - **顶部右上角**：在顶部 HUD 右上角新增醒目的暗红胶囊按钮 **`[关闭 (Q)]`**，无论是点界面右上角还是右下角均可秒退；
- **Per-Monitor V2 高 DPI 感知注入**：在 `viewport_manager` 中集成 `shcore.SetProcessDpiAwareness(2)`，确保鼠标坐标与图像物理像素 1:1 绝对严丝合缝；
- **主循环解耦安全析构**：回调函数仅安全设置 `self.is_running_gui = False`，由主循环下一拍统一完成安全退出与窗口析构，彻底杜绝底层句柄冲突。

## [2026-09-13] - 离线精度体检台“3D 双四棱柱空间虚实对比 (Dual-Prism 3D Pose Comparison)”与好样本视觉强化

### 1. 痛点根治与用户心声实现
- **体验不到好样本状态的痛点根治**：
  - 过去体检台仅渲染 2D 像面角点残差线。当样本质量极佳时，反推框与实测角点重合且残差箭头接近 0，浅灰色线条融入暗底，导致画面视觉反馈极度贫乏；
  - 本次更新为所有合格达标的好样本赋予**高辨识度的纯正稳态翠绿 3D 四棱柱与高反差发光标牌**：`[PASS] Tag #tid: 0.12mm (0.35px)`，一打开图片即可直观感受好样本整齐耸立在标靶纸面上的稳态质感；
- **BA 平差理论位姿 vs 单帧抓取实测位姿的 3D 双棱柱空间虚实对比**：
  - **绿色实心四棱柱 (BA 理论真值)**：由当前机位外参 $T_{c\_w}$ 与两阶段 BA 平差优化后的全局地图 $T_{w\_t}$ 复合反推所得：$T_{c\_t}^{BA} = T_{c\_w} \cdot T_{w\_t}$；
  - **金黄色/橙红色实测四棱柱 (单帧抓拍)**：由当前相片检出的 4 个角点经高精单靶 PnP（`SOLVEPNP_IPPE_SQUARE`）直接解出的局部实测姿态；
  - **高质量达标样本**：两座四棱柱**严丝合缝、完全重叠吸附**，展现无空间位移偏差的完美重合；
  - **偏差/需回审样本**：实测金黄柱与绿色 BA 柱在空间中产生**肉眼立即可见的空间错位与倾角偏转**，两柱顶盖中心拉出红色加粗空间残差偏差线，一眼看透是深度偏差还是法向量倾斜！

### 2. 双视图一键平滑切换
- 底部控制栏常驻新增 **`[3D双棱柱(T)]` / `[2D残差(T)]`** 切换按钮；
- 支持键盘快捷键 **`T`** 一键在【3D 双棱柱空间虚实对比模式】与【2D 像面角点残差矢量模式】之间瞬间切换；
- 2D 模式同步强化好样本视觉，赋予清晰绿底高对比度标牌。

## [2026-09-13] - 全局视口“以鼠标为中心 (Mouse-Centric)”无级滚轮缩放与中键平移漫游引擎

### 1. 核心特性与设计理念
- **以鼠标指针为锚点（Mouse-Centric Zoom）**：
  - 用户滚轮滚动缩放时，**鼠标下方的原图像素在整个缩放过程中严格纹丝不动**，实现如 Photoshop/CAD 等工业软件般精准随心的观察体验；
  - 缩放范围无级平滑支持 `1.0x`（全图等比适配）至 `8.0x`（微米/亚像素级极致放大）；
- **鼠标中键平移漫游（Middle-Button Pan）**：
  - 按住鼠标中键滚轮拖拽即可在视口内自由平移漫游，松开中键即止；
  - 智能边界阻尼约束（Bounding Constrain），防止画面脱出视口；
  - 与鼠标左键（单击翻转标靶、点击按钮）、右键（弹出标靶菜单）**完全正交解耦，零操作冲突**；
- **一键视口复位（Reset Zoom）**：
  - 支持快捷键 `0`、`Z` 或**双击鼠标中键**，毫秒级复位至 `1.0x` 全图适配初始状态；
- **半透明状态指示徽章（Zoom Badge）**：
  - 处于放大状态时，在视口右上角自动优雅悬浮磨砂半透明胶囊徽章：`[ 2.4x 放大 | 中键拖拽 | 0 复位 ]`，给用户清晰的视觉操作提示。

### 2. 高性能动态可见 ROI 局部裁剪渲染（< 2ms / 60+ FPS）
- **性能挑战**：若对 1080P/4K 原图在 8.0x 放大下直接执行全局 resize，图像尺寸将高达 15360x8640，单帧渲染耗时将从 2ms 激增至 60ms 以上并带来巨大内存突增；
- **数学几何 ROI 求解**：
  - `ViewportManager.render_viewport` 采用精确的双向 ROI 映射算法；
  - 实时计算窗口视口内当前可见的 `dst` 物理矩形，反向几何映射到原图 `src` 的采样浮点边界，仅裁剪并在视口内局部 resize；
  - 无论缩放 1 倍还是 8 倍，CPU 耗时均恒定在 1~2ms 内，内存零波动，操作无比丝滑流畅。

### 3. 双向高精度坐标变换保证点击 100% 精准
- `win_to_img_coords` 与 `img_to_win_coords` 实时融入 `user_zoom` 与 `(pan_x, pan_y)` 矩阵；
- 放大后直接使用鼠标左键点击标靶多边形内部，点击命中判定与状态翻转仍然 100% 精准可靠。

### 4. 覆盖模块与双工序全面接入
- 工序 4 观测样本人工审核画板（`tools/calibration/tag_manifest_reviewer.py`）；
- 工序 P 离线精度体检工作台（`tools/calibration/tag_offline_verifier.py`）；
- 底层视口核心通用引擎（`src/utils/viewport_manager.py`）。

## [2026-09-13] - GUI 全局 Emoji 乱码根治与分段胶囊乒乓开关 (Segmented Control) 工业化重塑

### 1. 彻底根治 OpenCV 字符集问号乱码 (`?` / `??`)
- **乱码病根揭秘**：OpenCV 的原生 Hershey 矢量引擎仅支持标准 ASCII 码，Windows/Linux 下即便中文字体可用，但大多数工业字体（如 `simhei.ttf`）均无 Unicode 扩展 Emoji 码位（如 `🚨`, `✏️`, `🔄`, `🚀`, `💾`, `🚪`, `✅`, `❌`, `⚡`, `🎯`, `📋` 等），导致渲染 fallback 产生大量成对或单个问号 `?` / `??`，破坏了界面专业度与可读性；
- **全栈净化与规范化**：
  - 对四大核心 GUI 与视口模块（`tag_offline_verifier.py`, `tag_manifest_reviewer.py`, `tag_calibration_verifier.py`, `viewport_manager.py`）进行全局净化，剔除所有 Emoji 图标；
  - 门限准入与报告状态全面采用标准工业文本徽章：`[PASS] 达标`、`[WARN] 警告`、`[FAIL] 超标/嫌疑`；
  - 按钮文字与快捷键标签统一为工业高对比度格式：`[ 重新平差 (B) ]`、`[ 退出 (Q) ]`、`[ 审核 (R) ]`，杜绝任何字符乱码。

### 2. 分段胶囊乒乓开关 (Segmented Control Toggle)
- **拒绝颜色混乱与状态含混**：废弃过去将两个状态混在单个文本按钮内的陈旧做法（避免用户无法分辨当前到底哪个状态被激活）；
- **全新通用组件 `draw_segmented_toggle()`**：
  - **激活态（Active）**：纯色高亮底板（翡翠绿/青蓝等语义色）+ 加粗纯白文字 + 前缀 `[*]` 标示；
  - **未激活态（Inactive）**：深灰低反差暗底 + 浅灰文字 + 前缀 `[ ]` 标示；
  - **一目了然**：在视觉上形成极其强烈的亮暗反差与胶囊滑块质感，并在开关旁直接显示快捷键；

    - 工序 P 离线体检台：`[*] 全量浏览 (N) | [ ] 仅回审 (F)`
    - 工序 4 审核画板：`[*] 全量浏览 (N) | [ ] Tag#X (Tab)`，`[* 本帧保留 (X)]` vs `[x 已剔除此帧 (X)]`
    - 工序 5/7 在线 AR 验证器：`[ 实时动态 (LIVE) | 静态锁定 (Tab) ]`，`[ 批次: 30F | 60F (W) ]`

### 3. 统一工业级按钮组件 `draw_styled_button()`
- 统一定义于 `src/utils/viewport_manager.py`，支持 `normal`, `primary`, `success`, `danger`, `warning`, `info`, `purple` 七大语义化工业暗色系；

### 2. 通用视口管理引擎与屏幕防遮挡解耦架构 (`ViewportManager`)
- **背景两难根治**：
  - 过去 1080P 画面直接在图上画按钮后展示，在 Windows 笔记本小屏或 125%/150% 缩放下，系统任务栏上可用高度仅约 680~860px，导致**底部操作按钮彻底掉出屏幕外被任务栏遮挡**；
  - 若简单等比缩小整图，按钮与文字也随之变小模糊，难以辨认与点击。
- **架构方案：【固定高清晰度 UI 栏 + 中间图像视口等比缩放 (Fixed UI Bars + Viewport Aspect Fit)】**：
  1. **Win32 安全工作区感知 (`get_safe_screen_size`)**：通过 `SPI_GETWORKAREA` 自动探测排除任务栏后的安全可用宽高，保证窗口默认 100% 严密容纳在屏幕内；
  2. **动态 Resize 与窗口最大化自适应重排 (`sync_window_size`)**：
     - 在事件循环中实时调用 `cv2.getWindowImageRect` 感知真实物理尺寸；
     - 用户拖拽窗口边框缩放或点击“最大化”时，系统毫秒级重新生成全分辨率画布，中间视口动态铺满，画面更大更清晰；
     - **底部操作按钮栏永远 100% 牢牢 Align 对齐在窗口真正最底部**（`win_h - bottom_bar_h`），彻底解决最大化时按钮悬空脱节的痛点；
  3. **视口分层渲染 (`render_viewport`)**：
     - **顶部 HUD 栏**：物理像素绘制状态信息与门限指示灯；
     - **中间视口**：相机 1080P 原始画面等比居中自适应缩放（Letterbox 留边），画面全貌 100% 可见、无畸变；
     - **底部按钮栏**：在窗口物理像素上以恒定字号饱满呈现所有操作按钮，绝对常驻视线下方，鼠标命中极为容易；
  4. **双向无损坐标映射**：
     - `win_to_img_coords`：鼠标点击窗口物理像素精准反算原图坐标，非视口区域安全返回 `None`；
     - `img_to_win_coords`：标靶原图坐标精准映射至窗口当前视口位置。

## [2026-09-12] - 标定系统重大架构升级：五步黄金工序、离线超精提取引擎与智能闭环握手

### 1. 核心架构升级：在线采图流畅度与离线建图极致精度的彻底解耦
- **背景痛点**：过去采图向导与建图提取耦合，必须使用折中的参数，既要保证 30ms 实时流畅，又容易在暗角、背光和远端发生标靶漏检；

## [2026-09-13] - 标定系统重大功能升级：独立离线标定精度体检与 Leave-One-Out 盲测批量验证引擎

### 1. 核心设计哲学：闭环验证与工序解耦
- **明确边界定位**：
  - **人工审核 (工序 4)** $\rightarrow$ 清洗 BA 的**输入**（剔除模糊、倾角过大、严重遮挡的坏观测，保证 BA 求解不被污染）；
  - **离线体验 (工序 P / 25)** $\rightarrow$ 严格验证 BA 的**输出**（逐帧逐 Tag 留一盲测，检验空间地图绝对几何精度，排查系统性偏差与漏审坏帧）。
- **完整六步闭环流水线**：
  $$\text{[1 制靶]} \longrightarrow \text{[2 采图]} \longrightarrow \text{[3 超精重提取]} \longrightarrow \text{[4 交互审核]} \longrightarrow \mathbf{\text{[P 离线体检]}} \longrightarrow \text{[5 AR验证/BA平差]}$$

### 2. 核心技术特性 (`tag_offline_verifier.py`)
1. **逐帧全标靶 Leave-One-Out (LOO) 盲测**：
   - 遍历每一张采图中的每一个已知标靶 $T_{blind}$，物理扣除后由剩余标靶通过超定 RANSAC PnP 姿态解算反推相机位姿；
   - 将 $T_{blind}$ 的 3D 世界角点投影回像平面，计算逐角点欧氏像元误差（$px$）与空间物理偏差（$mm$）；
2. **双模数据源自适应支持**：
   - **已审核清单模式 (`--source manifest`)**：直接读取 `tag_observations.yaml`，严格基于人工清洗后的有效样本评估 BA 地图内聚质量，22 帧仅耗时 **6.1 秒**；
   - **原图重检测模式 (`--source images`)**：对磁盘 1080P 原始图独立重跑双路互补融合检测，结合 RANSAC 解算，反向自动捕捉人工审核遗漏的瑕疵帧；
3. **稳健 MAD 统计与异常预警体系**：
   - 废除传统容易被重度离群值抬升的标准差 $\sigma$ 门限，改用中位数绝对偏差（MAD）结合天花板阈值；
   - 自动检测并标出“系统性偏差嫌疑标靶”（中位误差高于全局 2 倍）与“建议回审帧”；
4. **大成报表与图示化深度分析**：
