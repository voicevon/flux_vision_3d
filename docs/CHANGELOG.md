### 2. 单靶 PnP 平面二义性 180° 翻转根治
- **病因**：`solve_single_tag_pnp` 采用 `SOLVEPNP_IPPE_SQUARE`，平面靶 PnP 天然存在双解二义性 (两解沿靶面内一轴相差约 180°、法向翻转)；斜视 (约 45°) 时两解重投影误差之差缩至像素噪声量级，纯误差择优会间歇性选中翻转解，表现为在线识别蓝棱柱与地图理论绿棱柱相差 180° (Z 轴反向)；
- **修复**：`src/calibration/offline_engine.py` 与 `tools/calibration/tag_map_builder.py` 的 `solve_single_tag_pnp` 统一新增 `expected_z_cam` 法向先验参数——先剔除法向与先验反向的翻转解再按误差择优，先验下无同向合格解时拒绝输出 (防错优先)；建图版同步补齐深度非法解过滤；
- **先验接入** (6 处调用点)：地图内 Tag 用 BA 理论位姿法向，地图外 Tag (动态目标) 退用"标靶朝向天空"先验；tracker/studio 渲染与目标测距全部接入；
- **验证**：合成数据参数扫描 (距离 500~1200mm × 噪声 0.3~1.0px × 边长偏差 0~2%，5400 样本)：无先验翻转率最高 23%，带先验后 **0 翻转**。

## [2026-09-15] - 工况与场景管理中枢 (Scene Hub) 架构解耦与零卡顿性能跃升

### 1. 鼠标悬停与场景加载卡顿彻底根治 (13s $\rightarrow$ 0.004ms)
- **性能病因切片**：
  1. `CalibrationScene.load()` 在实例化时盲目执行 `refresh_stats()`，使用纯 Python `yaml.safe_load` 反复从磁盘读取解析 70KB 观测数据 YAML，单次耗时达 8~13 秒；
  2. `HubRenderer` 逐帧向底层 SceneManager 穿透调用 `get_active_scene()`，每帧均触发 YAML 磁盘重析；
  3. 鼠标在窗口内只要产生 1px 微移动，OpenCV GUI 便执行全量全屏重绘，包含 50+ 处中文切片光栅化与复合图元绘制。
- **三重治本架构优化**：
  1. **元数据惰性反序列化**：`CalibrationScene.load(force_refresh=False)` 默认直接信赖 `scene_meta.yaml` 中持久化的状态字段，场景初次装载耗时由 8.2 秒降至 **41 毫秒（提速 200 倍）**；
  2. **活动场景内存多级缓存**：`CalibrationSceneManager` 建立内部活动场景内存缓存；`HubState` 统一从内存场景列表索引，场景数据读取实现 **0ms 响应**；
  3. **帧级命中区碰撞缓存 (Hit-box Cache)**：`HubRenderer` 实现 `_get_interactive_hover_key()`，鼠标移动只要未跨越交互热区边界，直接跳过全屏绘制并零拷贝返回已缓存画布。**Hover 响应耗时缩减为 0.004 ms（折合 248,000 FPS）**，彻底告别界面冻结。

### 2. 概念定位升级与相机取流架构解耦
- **概念升维**：从“标定驾驶舱”重塑为“**工况与场景管理中枢 (Scene Hub)**”——将场景确立为纯粹的“数据容器与工程工作空间 (Workspace)”，与相机传感器硬件和标定算法彻底解耦；
- **采图向导外部委托**：彻底移除 Scene Hub 内部冗余的 USB 相机后台取流与 `MODE_CAPTURE` 状态机，杜绝抢占相机硬件句柄。用户按 `[C]` 键时，由 Scene Hub 子进程无缝拉起专用向导 `tag_capture_wizard.py`，采图结束后平滑自动重载样本；
- **沙盒隔离状态胶囊**：底部状态栏右下角由旧版相机 FPS 升级为沉浸式沙盒状态胶囊（`SANDBOX: ★ 生产运行基准` / `SANDBOX: 已平差 (RMSE ...)` / `SANDBOX: 草稿沙盒`），无需连接相机硬件即可开展全量场景沙盒管理。
