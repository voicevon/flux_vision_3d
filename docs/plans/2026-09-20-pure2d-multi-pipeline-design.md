# 芦笋纯 2D 多技术路线感知与叠压拓扑剥层设计规范

## 1. 业务目标与核心约束

### 1.1 核心边界约束 (Pure 2D Constraint)
- **彻底脱离 3D 点云依赖**：工业现场当前输入为纯 2D 彩色图像（RGB/BGR），所有边缘检测、直径测量、骨架提取、叠压与层级遮挡判定必须 100% 建立在纯 2D 图形与几何拓扑之上。
- **空间高度虚拟化映射**：在输出 3D 抓取或分拣目标位姿时，统一采用基准工作面物料几何特征推导（标称高度 + 直径半高补偿），不假设任何深度图有效输入。

### 1.2 感知技术路线三元架构
在离线诊断工具（`tools/asparagus_offline.py`）与核心算法包中，提供三条可秒级插拔切换的研发技术路线：
1. **路线 A：距离场脊线法 (Ridge Tracing)**
   - 欧氏距离变换场 (Distance Transform) + 垂向局部极大值抑制 (NMS) + 横向骨架闭合。
2. **路线 B1：极性扫描法 (Polarity Scanline)**
   - 垂直列扫描 (Vertical Scanline) + 梯度极性正负跃变配对 (+Gy / -Gy) + 极性对称中线聚类 + 叠压拓扑剥层。
3. **路线 B2：分线段提取法 (Segment Topology)**
   - 保边滤波 + 方向导向边缘提取 (仅保留接近水平边缘) + 平行线段成对拓扑配对 + T型断点拓扑图。

## 2. 路线 B1：极性扫描法 (Polarity Scanline) 详细算法设计

### 步骤 1：ROI 预处理与微小杂散边缘抑制
- **自适应传送带 ROI 裁切**：锁定传送带区域，屏蔽左右机械滑轨与背景反光。
- **色彩与亮度增强**：转换为灰度图，使用小核双边滤波（Bilateral Filter, $d=5, \sigma=30$）平滑细微纹理，同时保持芦笋上下边缘的高频阶跃。
- **边缘杂散点消融**：进行极小尺度形态学开运算 ($3\times3$)，消除微小噪点；结合连通域长度过滤，剔除像素长度小于阈值（如 30px）的碎屑噪声。

### 步骤 2：方向导向滤波 (Directional Edge Filter)
- **计算垂直方向梯度**：针对主要沿 X 轴输送的芦笋，上下边界在垂直 Y 方向具有显著的亮度导数。计算 $G_y = \text{Sobel}(Gray, CV\_32F, 0, 1, ksize=3)$。
- **角度方向筛选**：剔除切线与 X 轴夹角过大（$>25^\circ$）的垂直端头截断线与机械划痕，只保留近似水平走向的双侧边缘候选。

### 步骤 3：垂直列扫描与极性配对 (Polarity Scanline Matching)
- **扫描网格**：以步长 $\Delta x = 6\text{px}$ 沿 X 方向遍历每一列。
- **极性跃变识别**：
  - 芦笋上边缘由暗（背景）到亮（物料），梯度为正峰值（$+G_y$）；
  - 芦笋下边缘由亮（物料）到暗（背景），梯度为负谷值（$-G_y$）；
- **物理间距配对约束**：
  - 寻找相距在合理物理直径内（$8\text{mm} \le \text{dist} \le 35\text{mm}$）的 $(+G_y, -G_y)$ 对。
  - 多根并排时，每一根芦笋均形成一组自成闭环的 $(+G_y, -G_y)$ 对，贴合处的边缘因极性相反天然解耦！
- **中心脊点提取**：对每对有效极性跳变计算几何中点 $y_c = \frac{y_{\text{top}} + y_{\text{bottom}}}{2}$，直径 $d = y_{\text{bottom}} - y_{\text{top}}$。

### 步骤 4：主干线聚类与连续性拟合
- 将各列的中点按横向邻近度（DBSCAN 或基于方向的游程追踪）聚类为单根连续中轴线。
- 采用 `cv2.fitLine` 进行中轴鲁棒直线拟合，得出单根芦笋长度、偏航角（Yaw）及几何中心。

## 3. 叠压与上下层仲裁机制：循环拓扑剥层 (Occlusion Graph Peeling)

针对多根芦笋相互交叉、堆叠的难题，设计纯 2D 拓扑剥层循环算法：

```
                    [输入所有检测到的中轴段与轮廓]
                                  │
                                  ▼
      ┌─────────────► 【第 1 轮：检测交叉干涉与 T 型截断】
      │               · 遍历所有主干两两相交点
      │               · 检查交点两侧边缘的连续性：
      │                 * 边缘完整穿过交点者标记为：上层（Father）
      │                 * 边缘在交点处断开呈 T 型者标记为：下层（Child）
      │                               │
      │                               ▼
      │               【第 2 轮：构建遮挡有向无环图 (DAG)】
      │               · 建立有向边：Upper → Lower
      │               · 统计每个物料的入度 (In-Degree = 被压计数)
      │                               │
      │                               ▼
      │               【第 3 轮：锁定无遮挡纯顶层物料】
      │               · 筛选 In-Degree == 0 的目标作为顶层物料
      │               · 将其赋予最高抓取优先级 (Top 1, Top 2, ...)
      │                               │
      └──────(迭代剥离)               ▼
          更新剩余物料 ◄─── 【第 4 轮：下层断线重构与循环退出】
                           · 若存在被压断的下层碎片，在此轮剥离顶层遮挡后，
                             对同方向断线尝试延长拼接。
                           · 循环直到所有剩余可识别单体均无更上层遮挡。
```

## 4. 路线 B2：分线段提取法 (Segment Topology) 架构概览
- 基于细化骨架提取平行线段（Segment Extraction）；
- 计算线段之间的重叠重合度（IoU-along-axis）与法向对称性；
- 同样接入上述通用的“叠压拓扑剥层”仲裁器。

## 5. UI 与系统集成交互规范
- **离线工具下拉框**：
  - `路线 A: 距离场脊线法 (Ridge Tracing)`
  - `路线 B1: 极性扫描法 (Polarity Scanline)`
  - `路线 B2: 分线段提取法 (Segment Topology)`
- **步骤动态切换药丸**：
  - 针对 B1 暴露步骤：`1.预处理` -> `梯度极性` -> `极性配对` -> `2.主干拟合` -> `3.顶层位姿`
  - 针对 B2 暴露步骤：`1.预处理` -> `线段提取` -> `双轨配对` -> `2.中线拓扑` -> `3.顶层位姿`
- **纯 2D 安全防撞拦截**：
  - Z 轴全部采用标称安全工作台基准高度计算，杜绝任何点云缺失崩溃或野指针。
