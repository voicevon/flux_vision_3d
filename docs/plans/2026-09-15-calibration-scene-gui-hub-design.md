# 标定采样场景管理 GUI 驾驶舱 (Scene Hub) 技术设计方案

## 1. 概述与设计背景
在手眼标定与 AprilTag 空间建图流程中，不同工况、安装批次与光照环境下需要采集并维护多组独立的标定数据。前一阶段已实现了底层的无损自包含场景沙盒模型（`CalibrationSceneManager`）。为了彻底摆脱纯文本终端选择场景的抽象感，实现“看图选场景”、“所见即所得”，本系统设计并落地一款基于 OpenCV 纯原生渲染的高性能深色工业视觉控制台——**标定场景管理 GUI 驾驶舱（Scene Hub）**。

Scene Hub 整合了**场景相册浏览、全量历史质检体检看板、原地无缝实时采图、一键直通离线 Studio 深度平差、原子发布至生产环境**的全链路闭环。

### 双模视口状态定义：
1. **状态一：画廊与数据视口（`MODE_INSPECTOR`，默认）**：
   - 展现该场景的缩略图相册，选中单帧可在大图预览区进行高精细节检查；
   - 实时解析场景元数据与平差精度报告，清晰给出当前场景的评级（如 A+ 极优、B 需补拍等）；
2. **状态二：原地无缝采图视口（`MODE_CAPTURE`，按 `[C]` 瞬间激活）**：
   - 右侧主舞台原地切为实时相机画面，自带 AprilTag 绿色动态跟踪框；
   - 按 `[Space]` 空格键拍摄，触发 50ms 屏幕柔和闪白动效；
   - 自动在 `<scene_dir>/raw_images/` 写入新帧并自增图片计数，刷新缩略图列表；
   - 按 `[ESC]` 或 `[C]` 切回画廊，按 `[S]` 直接拉起离线 Studio。

## 4. 全链路快捷键与操作映射

| 模式 | 键位 | 对应操作 | 视觉反馈与行为 |
| :--- | :---: | :--- | :--- |
| **通用** | **`[ESC] / [Q]`** | 退出当前状态（采图时退出回画廊；画廊时退出回 CLI 菜单） | 平滑返回上一级 |
| **画廊模式** | **`[↑] / [↓]`** | 在左侧场景卡片流中切换选中项 | 光标移动，右侧数据与缩略图秒级同步 |
| | **`[Enter]`** | 将选中的场景设为**全局活动场景** | 出现绿色 `▶ [当前活动]` 标志，写入 `.active_scene` |
| | **`[←] / [→]`** | 在相册缩略图中左右浏览照片 | 高亮框移动，中间大视口展示对应高清大图与角点 |
| | **`[C]`** | **启动原地实时采图** | 右侧视口切为 1080P 实时视频取流画面 |
| | **`[S]`** | **一键启动离线 Studio 深度平差** | 唤起 Studio 窗口，退出后自动刷新平差残差 |
| | **`[N]`** | **新建场景** | 界面弹出新别名输入框，秒级创建并自动定位到它 |
| | **`[K]`** | **克隆场景** | 复制当前场景的照片和参数，生成新版本对比实验 |
| | **`[P]`** | **一键发布至生产环境** | 将该场景地图原子同步至 `config/tags_map.yaml` |
| | **`[V]`** | **在资源管理器中打开** | 在系统资源管理器中打开该场景文件夹 |
| | **`[X]`** | **安全删除场景** | 弹出二次确认，安全防呆（禁止删除当前活动场景） |
| **采图模式** | **`[Space]`** | **空格连拍** | **屏幕闪白动效**，图片即刻归档进场景，采图张数 +1 |
| | **`[S]`** | **拍完立即平差** | 结束取流，直接唤起 Studio 对刚拍的照片启动平差 |

## 5. 性能与鲁棒性考量
1. **缩略图内存 LRU 缓存**：图片加载后自动缓存 120×90 像素微缩图，避免磁盘重复读写，界面始终维持 60 FPS 满帧刷新；
2. **相机双模与非阻塞**：优先尝试 RealSense 物理硬件，若未插入相机自动优雅降级为 `--mock` 仿真画面，杜绝崩溃；
3. **CLI 命令行双重保障**：在无图形界面的远程 SSH 环境下自动无缝回退至文本式 `submenu_scene_manager`。
