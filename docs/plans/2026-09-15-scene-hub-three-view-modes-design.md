## 1. 背景与目标

### 1.1 问题一：主菜单按 `H` 进入二级 CLI 菜单延迟约 2 秒
- **原因**：每次调用 `check_env_status()`，`pyrealsense2` 均重新执行 `rs.context().query_devices()` 阻塞扫描枚举物理 USB 总线（实测耗时 1.47 秒），外加重复的 YAML 扫描解析。
- **目标**：在主菜单进入时已有 `status`，进入二级菜单时复用缓存或直接传递，将按键响应时间从 1.6 秒降至 2 毫秒以实现秒开。

### 1.2 问题二：Scene Hub 支持 3 种视图模式（标准 / 全宽大图 / 纯净无相册看板）
- **目标**：满足操作员在“无需巡检照片，仅需纯粹查看场景几何健康与平差指标”时的需求。
- **选定方案（方案 B）**：
  - **左侧场景栏固定 340px 绝对不动**，最大化保留操作员的卡片位置与按钮肌肉记忆；
  - **右侧 940px (340~1280)** 舒展呈现“纯净综合体检与几何健康大看板”，相册缩略图和大图预览完全关闭/隐藏；
  - **顶部标题栏增加三段式 Tab 胶囊**：`[ ⊞ 标准三栏 | ⤢ 全宽大图 | ▤ 纯净看板 ]`，直观指示当前状态并支持鼠标点击切换；
  - **键盘按键 `[F]` 保持循环切换**：`标准` $\rightarrow$ `全宽大图` $\rightarrow$ `纯净看板` $\rightarrow$ `标准`。

## 2. 界面布局与三模态定义

### 2.1 状态常量与切换状态机 (`HubState`)

```python
class HubState:
    VIEW_STANDARD = "standard"    # 模式1: 标准三栏 (左340, 中460, 右480)
    VIEW_EXPANDED = "expanded"    # 模式2: 全宽大图 (左340, 右940大图铺满)
    VIEW_DASHBOARD = "dashboard"  # 模式3: 纯净看板 (左340, 右940纯体检健康，无相册)

    def cycle_view_mode(self):
        """按 [F] 循环切换三模态"""
        modes = [self.VIEW_STANDARD, self.VIEW_EXPANDED, self.VIEW_DASHBOARD]
        curr_idx = modes.index(self.view_mode)
        self.view_mode = modes[(curr_idx + 1) % len(modes)]
```

### 2.2 顶部 Header 三段式切换胶囊 (Segmented Control)

在 Header 中间偏右位置（x: 520~760, y: 10~40）渲染科技风三段式微型 Tab：
- `[ ⊞ 标准 ]` (x: 520~595)
- `[ ⤢ 大图 ]` (x: 597~672)
- `[ ▤ 看板 ]` (x: 674~749)
- 当前激活模式高亮（荧光绿高亮框 + 亮绿文字），其他模式沉稳暗绿；鼠标点击任意一个即可秒切对应模式。

### 2.3 模式 3：纯净体检健康看板 (Right 940px) 视觉布局

右侧 340~1280 (宽 940px, 高 620px) 采用宽松舒适的 4 块工业看板布局：
1. **顶部元数据与质检放行卡片 (y: 65~160, 宽 908)**：
   - 当前场景名称、物理 ASCII ID、样本帧数、BA 求解状态；
   - 醒目大号放行标签：`[ 工业质检已放行 (RMSE < 0.8px) ]` 或 `[ 待平差优化 ]`。
2. **中层指标双卡片 (y: 172~350)**：
   - 左卡片 (宽 444)：核心精度指标（全局 RMSE、有效帧比例、覆盖 Tag 总数、观察值条数）；
   - 右卡片 (宽 444)：3D 空间几何健康度（空间最大基线跨度 mm、环路闭环数、单 Tag 冗余度）。
3. **底层 Tag 覆盖分布矩阵 (y: 362~650, 宽 908)**：
   - 清晰列出当前场景已检测到的所有 Tag ID 及其出现频次分布徽章；
   - 提示操作员若需查看照片大图，可随时点击顶部 `[ ⤢ 大图 ]` 或按 `[F]` 恢复。

## 3. 交互与快捷键

| 交互动作 | 目标操作 | 适用模式 |
| :--- | :--- | :--- |
| **按 `[F]`** | 顺次循环切换：标准 $\rightarrow$ 大图 $\rightarrow$ 纯净看板 | 全部模式 |
| **鼠标点击顶部 Tab** | 直接跳入对应的视图模式 (标准/大图/看板) | 全部模式 |
| **按 `[↑/↓]` / 滚轮** | 切换选中的场景（左侧完全固定，卡片位置不跳变） | 全部模式 |
| **点击卡片 `[P 生效生产]`** | 将当前活动场景一键发布至生产 | 全部模式 |
