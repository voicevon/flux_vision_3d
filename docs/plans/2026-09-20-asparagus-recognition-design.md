# 芦笋位姿识别算法设计与阶段复选交互规范 (Design Document)

## 1. 设计目标与业务背景
针对现场芦笋分拣场景中出现的“并排芦笋粘连合并”、“抓取准星落入空隙”、“单根芦笋被切断”等严重识别缺陷，建立透明可解释、支持单步可视化审计的三阶段视觉解算体系。
在 GUI 上通过 **3 个 Checkbox（阶段复选框） + 1 个【识别执行】按钮**，让工程师能够灵活控制解算深度并实时检查中间阶段质量。

---

## 2. 交互设计：3 个 Checkbox + 1 个执行按钮

在顶部操作栏（位于工位地图下拉框右侧、退出按钮左侧）部署核心控制控件：

1. **复选框控件 (Checkboxes)**：
   - `[✓] 1. 前景` (默认勾选)
   - `[✓] 2. 骨架` (默认勾选)
   - `[✓] 3. 位姿` (默认勾选)
2. **执行按钮 (Action Button)**：
   - **【识别定位 [空格]】**
3. **交互逻辑**：
   - 用户可以任意勾选或取消勾选阶段 1、2、3；
   - 点击【识别定位】（或按空格键）时：
     - 若勾选至 **阶段 1**：执行传送带 ROI 裁切 + 前景物料提取，主视口呈现半透明物料覆盖层（验证物料是否完整抠出）；
     - 若勾选至 **阶段 2**：进一步执行距离变换中轴骨架切分与多实例轮廓提取，主视口呈现彩色单根实例与白色中轴脊线（验证并排粘连是否被成功切开）；
     - 若勾选至 **阶段 3**（全选）：执行完整的长径测量、顶层排序、抓取点计算与 G-code 生成，主视口呈现带光晕高亮的 Top 3 目标与详细数据卡片。
   - 用户点击不同的 Checkbox 即可即时切换中间视口显示对应阶段的可视化结果，无需重新耗时计算！

---

## 3. 三阶段算法深度架构

### 阶段 1：传送带空间约束与自适应物料前景提取 (Conveyor ROI & Plant Foreground)
1. **Conveyor 传送带物理区域自适应裁剪**：
   - 黑色传送带在图像上横跨 X 约 750~1520px（依标定与物理机台自适应提取）；
   - 强行屏蔽左右两侧机械臂滑轨、立柱、AprilTag 标靶反光等干扰区域。
2. **超绿/Lab 双重自适应植物色域提取**：
   - 黑色背景灰度通常在 15~40，芦笋在 100~180；
   - 利用超绿指数 $2G - R - B$ 以及 Lab 色彩空间中的绿色色度 $a^*$ 维度，结合局部 Otsu 自适应门限；
   - 摒弃盲目的大核形态学膨胀/闭运算，避免把相邻芦笋熔合成团。

### 阶段 2：距离变换中轴骨架提取与并排粘连切分 (Distance Transform & Spine Separation)
1. **距离变换 (Distance Transform)**：
   - 对前景掩膜计算逐像素到背景的最短距离；
   - 单根芦笋的几何中心会形成一条清晰的“山脊线 (Ridge)”，脊线处的距离值恰好等于芦笋的半径（约 7~18px）；
   - 两根并排接触的芦笋之间，距离值会出现明显的“鞍点/低谷”，自然提供切割分界线！
2. **局部极大值中轴脊线追踪 (Ridge Tracing)**：
   - 沿横向与法向检测局部峰值，提取每根芦笋的单像素连续中轴骨架；
   - 中轴线的长度直接对应芦笋有效长度，中轴线的斜率直接给出轴线倾角（Yaw）；
3. **分水岭 / 骨架聚类得到独立单根实例**：
   - 将中轴骨架作为种子点（Markers），对粘连区域执行精细切分，输出互不重叠的单根独立轮廓。

### 阶段 3：物理特征测算、Top 3 优选与抓取位姿解算 (Pose Estimation & Pick Ranking)
1. **沿脊线多点法向测厚 (Diameter Calculation)**：
   - 沿中轴骨架以 10px 步长做垂向截面采样，计算平均直径与极值；
   - 彻底解决外包围盒被并排物料撑大至 50~60mm 的虚假尺寸问题。
2. **Top 3 抓取优先级仲裁**：
   - 若有 3D 深度：相对工作台凸起净高度最大者优先（最顶层）；
   - 若为 2D 预览：几何完整度最高（长宽比例均衡、中心无叠压）者优先；
   - 选出最优的 3 根，赋予 `#1, #2, #3` 标号，并在画面与右侧面板全面呈现直径、长度、方向、高度。
3. **坐标变换与 G-code**：
   - 将主轴中心与倾角映射至 SCARA 机械臂坐标系，生成安全抓取 G-code。

## 4. 模块职责与变更范围
- `src/vision/asparagus_analyzer.py`：
  - 实现三阶段解算内核：`extract_foreground()`, `separate_spines()`, `estimate_poses()`；
  - 保存每阶段的中间可视化调试图：`vis_stage1` (前景掩膜图), `vis_stage2` (骨架切分图), `vis_stage3` (位姿卡片图)；
- `tools/asparagus_offline.py`：
  - 增加 3 个 Checkbox 控件渲染与鼠标点击事件响应；
  - 根据 Checkbox 状态驱动单步或全流程执行，并在中间视口切换展示对应阶段图层。
