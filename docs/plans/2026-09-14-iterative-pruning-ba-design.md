# 自动迭代残差剪枝平差 (Iterative Residual Pruning BA) 设计文档

- **创建日期**: 2026-09-14
- **作者**: Antigravity & User
- **目标**: 在 AprilTag 离线标定综合工作站 (Offline Studio) 中引入基于边际收益收敛与共视拓扑安全守门的全自动循环剪枝平差机制。

---

## 1. 背景与理论依据
在 AprilTag 多相机/多姿态空间平差过程中，极个别由于边缘大倾角、微虚焦或光照反光导致的高离差坏样本（Outlier）会通过最小二乘的平方惩罚项把全局标靶的位姿解算拉偏。
本功能借鉴摄影测量学 **Baarda 数据探测法 (Data Snooping)** 与 COLMAP/OpenMVG 的 **Iterative Bundle Adjustment with Outlier Filtering** 机制：
通过“初次解算 -> 离差排序 -> 剔除坏样本 -> 重平差”的正反馈闭环，彻底消除粗差，快速逼近全局最优解。

---

## 2. 算法核心流程与终止判定

### 2.1 循环状态机
1. **状态快照**: 启动前深拷贝当前审核清单 (`manifest`) 与平差结果，支持一键无损撤销。
2. **基准平差**: 调用全局 BA 优化器求解当前观测下的标靶空间位姿与相机外参。
3. **残差计算与排序**:
   - 计算各帧有效观测标靶的重投影误差（像面像素误差 $e_{px}$ 与物理空间偏差 $e_{mm}$）。
   - 全局降序排序，锁定当前离差最大的 Top-K 标靶（默认每轮 1~2 个）。
4. **收敛与终止条件**:
   - **核心判定（边际收益收敛）**: $\Delta \text{RMSE} = \text{RMSE}_{t-1} - \text{RMSE}_t < 0.01\text{ px}$，表明粗差已全部剔除，高斯噪声下继续剪枝无收益，自动最优停机。
   - **最大轮数限制**: 默认上限 10 轮，防止极端振荡。
   - **急停支持**: 用户可在界面随时按空格键或点击急停。
5. **拓扑安全守门员 (Safety Guardrails)**:
   - **单靶最小观测度**: 任一 Tag 在全局的有效观测帧数不得 $< 2$。
   - **共视连通性**: 剔除该观测后，全局标靶必须依然维持单一连通图，禁止产生孤岛分量。
   - 若候选最大离差标靶会破坏拓扑，算法自动顺延寻找“次坏”且安全的标靶剔除；若已无安全可剔除项，立即安全停机。

## 3. UI 界面与交互规范

### 3.1 入口与排布
- 在 Offline Studio 底栏 `[全局平差 (B)]` 之后新增 **`[剪枝平差 (A)]`**（快捷键 `[A]`）。

### 3.2 运行中状态卡片 (居中磨砂半透明)
- 标题: `工序 5-Auto: 迭代剪枝平差中 (第 k/N 轮)...`
- 动态收敛指标与淘汰日志滚动显示。

### 3.3 结算与确认面板
- 显示初始 RMSE -> 最终 RMSE 与空间中位毫米偏差。
- 列出被自动剔除的样本明细。
- 提供两项决策操作：
  - **`[采纳结果 (Enter)]`**: 保持剪枝后状态，视口自动打叉，更新顶栏门限。
  - **`[撤销还原 (Esc)]`**: 恢复至快照状态，无损试错。
