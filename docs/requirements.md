# 系统需求与设计规格书

> **文档定位**：`flux_vision_3d` 的功能性 / 非功能性需求定义与里程碑进度追踪。  
> **适用读者**：需求评审、项目管理、验收测试。

---

## 1. 项目定位

- **项目名称**：`flux_vision_3d`
- **系统角色**：分拣系统的"视觉大脑"与主调度中心
- **核心使命**：基于 Intel RealSense D435 RGB-D 相机，对传送带上无序堆叠交叉的芦笋进行抗噪感知与空间遮挡拓扑推理，**100% 稳定提取最顶层可抓取目标**，解算世界坐标系下的抓取位姿 $(X, Y, Z, R)$，驱动 SCARA 机械臂完成自动化抓取，并向 Dealer 机构输出品质分拣指令。

---

## 2. 物理工况与硬件规格

| 组件 | 选型 | 关键参数 |
| :--- | :--- | :--- |
| **3D 传感器** | Intel RealSense D435 (主动红外双目) | 安装于传送带上方，大倾角俯视 $(\pm 30°)$；工作距离 $550 \sim 700\text{mm}$；视野 $50 \sim 60\text{cm}$ |
| **作业模式** | 间歇步进 (Stop-and-Go) | 传送带步进→停稳拍照→解算→分层抓取清空→下一段；时间滤波 4~8 帧，$\pm 0.8\text{mm}$ 测距跳动 |
| **执行机构** | 4 轴 SCARA + 双夹爪 | MKS Base V1.6, Marlin 2.0+, USB 虚拟串口 115200, 笛卡尔 `G1 X.. Y.. Z.. R.. F..` |
| **分发机构** | 8 级级联步进翻转 | ESP32, BLE 4.2/5.0 单播, `Target ID: 1~8` |
| **计算平台** | PC / 工控机 | Windows 10/11 或 Ubuntu 22.04, Python 3.11+, 单帧推理 $\le 200\text{ms}$ |

## 3. 核心技术挑战

堆叠分拣的核心瓶颈不是"检测出芦笋"，而是**在杂乱重叠中确定哪一根在最上层**。

| # | 物理风险 | 表现 | 算法应对 |
| :---: | :--- | :--- | :--- |
| 1 | 边缘飞点与并排粘连 | 细长圆柱边缘视差模糊，多根在深度图粘连 | 3D 浮凸初筛 + 黑帽暗缝切分 |
| 2 | 湿润表面镜面反光 | 蜡质/水膜红外过曝，中轴产生 0 值黑洞 | 激光 120mW + 脊线前 15% 分位数 |
| 3 | 大倾角透视短缩 | $\pm 30°$ 投影压缩物理长度 | 3D 空间两端点欧氏测距 |
| 4 | 深度高斯噪声 | 640mm 工作面存在微噪 | Temporal Filter 4~8 帧硬件积累 |
| 5 | 叠压拓扑闭环 | 三根互压导致拓扑死锁 | 自愈兜底：退化为绝对净高优先 |

| 编号 | 需求 |
| :--- | :--- |
| FR-2.1 | **模式 A (生产级)**：YOLOv8-seg 实例分割，输出像素多边形掩膜 |
| FR-2.2 | **模式 B (轻量级)**：HSV 二值化 + 自适应阈值 + 形态学轮廓提取 |
| FR-2.3 | 剔除面积过小（断裂碎屑）或贴靠视场边界的残损目标 |

### FR-3 脊线提取与深度抗噪

| 编号 | 需求 |
| :--- | :--- |
| FR-3.1 | 矩形/椭圆核 5~8px 腐蚀，剥除边缘 3~5mm 深度飞点 |
| FR-3.2 | 内缩掩膜与对齐深度图点乘，提取中轴脊线深度数组 |
| FR-3.3 | 前 15% 分位数 → 顶面高度 $Z_{top}$, 中位数 → 轴心高度 $Z_{center}$ |

### FR-4 空间遮挡分析与最上层仲裁

| 编号 | 需求 |
| :--- | :--- |
| FR-4.1 | 2D BBox/Mask 相交检测，建立重叠候选对集合 |
| FR-4.2 | **判据一 (高程差)**：$\Delta Z = Z_A^{top} - Z_B^{top}$，容差 $\delta = 4\text{mm}$ |
| FR-4.3 | **判据二 (几何连续性)**：深度差接近容差时，检测 T-junction 截断 |
| FR-4.4 | 构建遮挡 DAG $G=(V,E)$，入度为 0 的节点 = 最顶层可抓取物料 |
| FR-4.5 | **环路自愈**：闭环 ($A \to B \to C \to A$) 时退化为绝对净高优先 |
| FR-4.6 | **平铺防推挤**：同层平铺时优先抓取外侧边缘，由外向内剥离 |

### FR-5 位姿解算与品质分级

| 编号 | 需求 |
| :--- | :--- |
| FR-5.1 | PCA/最小外接矩形求长轴夹角 $\theta$，反投影得相机系 $(X, Y, Z)$ |
| FR-5.2 | 沿长轴扫描截面：平均外径 $D_{mm}$, 弧长展开长度 $L_{mm}$, 直线度 $S$ |
| FR-5.3 | 分级映射 → `Target ID: 1~8` |

### FR-9 空间多标靶标定与离线建图需求

| 编号 | 需求 | 验收标准 |
| :--- | :--- | :--- |
| FR-9.1 | **标靶排版与白名单管控** | 支持 AprilTag 16h5 (ID 0~29 共 30 枚) 40mm 物理尺寸 1:1 双页 A4 PDF 输出（附 100mm 校验尺）；支持基于配置文件的物理白名单硬锁机制 (`valid_tag_ids`)，实现零伪虚警。 |
| FR-9.2 | **双路互补高动态检测** | 构建“高光抗反光路 + 暗部低反差分位数动态拉伸路”双路互补架构，解决墨迹不纯（灰度 50~80）与大倾角漏检，实拍召回率提升 100%+。 |
| FR-9.3 | **平面 PnP 镜像二义性消除** | 引入水平工作台物理法向先验 ($R[1, 2] < 0$ 指向天空)，彻底消除单目正方形标靶前后翻折的“倒栽葱”伪解，确保 BA 初值物理正确。 |
| FR-9.4 | **物理与拓扑双重安全守门员** | 面积 $<120\text{px}$ 或深度超出工作区间 ($150\sim 2200\text{mm}$) 自动物理拦截；BFS 连通图拓扑遍历阻断孤立标靶与矩阵奇异崩溃。 |
| FR-9.5 | **极限两阶段 BA 空间建图求解** | 多标靶超定 PnP 初值估计 + 雅可比对角归一化 (`x_scale='jac'`) + Cauchy 粗平差 + MAD 统计清洗 + $10^{-9}$ 微容差精平差；输出 Quiver 残差场矢量图与 $3\sigma$ 置信度体检报告。 |
| FR-9.6 | **世界坐标系绝对锚定** | 以两枚特殊标靶的已知绝对坐标（机械臂坐标系）作为建图位姿与尺度锚定基准：Tag 0（原点标靶）= $(0, 0, 405)\text{mm}$，Tag 1 = $(0, 520, 196)\text{mm}$。BA 平差阶段保持以像素为单位；平差收敛后计算与保存地图时，引入该绝对坐标完成世界坐标系锚定与尺度解算，作为 Tag 边长（40mm）单一尺度参照之外更完整的基准；保存的地图中所有 Tag 位姿统一表达在该世界坐标系下。 |
| FR-9.7 | **六维坐标显示规范** | 标靶悬停详情框中，世界系 XYZ、BA 理论 XYZ、实测 XYZ 三组坐标各占一行完整显示（X、Y、Z 三值同行）；数值保留一位小数；数值前不显示 X/Y/Z 字母标识，改用固定列位排列（每行左起依次为 X、Y、Z 列）；三组数值小数点垂直对齐（X 列对 X 列、Y 列对 Y 列、Z 列对 Z 列），保证跨行读数可直接比对。 |

## 5. 非功能性需求

| 维度 | 要求 |
| :--- | :--- |
| **时延** | 单帧全流程 $\le 200\text{ms}$（$\ge 5$ FPS），满足机械臂抓放周期 1.5~2.5s；在线 PnP 外参定位 $\le 5\text{ms}$ |
| **空间与投影精度** | 离线 BA 建图标准数据 RMSE $\le 0.05\text{px}$，现场实采数据有效观测 RMSE $\le 4.5\text{px}$；静态锁定抖动严格 $0.00\text{mm}$ |
| **拓扑容错安全** | 共视图孤立或割裂时自动阻断并输出明确指引，永不抛出奇异矩阵致命崩溃；离线采图向导杜绝多边形噪点风暴卡死 |
| **环路保护** | 遮挡图异常循环时退化为最高绝对高度优先，永不死锁 |
| **空视野保护** | 无可抓取目标时平滑等待，不发送任何机械臂指令 |
| **防撞安全** | "抬起平移→垂直下落"原则；未标定状态坚决拦截相机高程直接传入 SCARA，强制降级为台面相对高度限制 ($\le 80\text{mm}$) |
| **环境适应** | 抗日光灯/条形补光灯，支持纸张反光与发灰墨色下的双路自适应互补检测 |
